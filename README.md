# Agentic AI Design Patterns

Python implementations of foundational AI agent architectures,
developed while studying agentic system design.

## Implemented Projects

### 01 — ReAct Agent (Tool Use)
An agent that can use web search, a calculator, and
a current-date tool through an iterative reasoning
and tool-execution loop.

### 02 — Planning Agent
A research agent that decomposes questions into
multiple steps, executes a plan, tracks progress,
and generates research summaries.

### 03 — Reflection / Critic Agent
A code-generation system using a generate-evaluate-revise
loop, with automated testing and a limited retry budget.

## Focus Areas
- LLM tool calling
- Agent orchestration
- Planning and execution
- Reflection and automated evaluation
- Python backend engineering

## Development
These are hands-on implementations based on the
Agentic Design Patterns field guide.
